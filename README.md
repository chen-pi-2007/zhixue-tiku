# 智学题库 · 刷题与错题本系统

上传"带答案的选择题试卷"(docx / txt / md),自动识别拆题,生成可以逐题作答的复习题库,自动收集错题本。

<p align="center"><a href="https://github.com/chen-pi-2007/zhixue-tiku/tree/stats"><img src="https://raw.githubusercontent.com/chen-pi-2007/zhixue-tiku/stats/stats.svg" alt="智学题库使用情况" width="840"></a></p>

**零依赖**:只需 Python 3.6+(纯标准库,无需安装任何第三方包、无需数据库,数据就是一个 JSON 文件)。

## 快速开始

双击 **`智学题库.exe`**：打开“智学题库”窗口（不用浏览器），右下角托盘出现蓝色“题”字图标。关窗口会缩到托盘，托盘右键「退出」才真正关闭。

- 单击托盘图标：打开窗口；已经开着时再双击 exe，只会把原来的窗口调出来，不会重复启动
- 右键菜单:开机自启(勾选)、打开数据文件夹、备份数据到桌面、退出
- exe 是单文件，可以直接发给别人；数据放在 `%LOCALAPPDATA%\智学题库`（exe 旁边有 `data/` 文件夹时用旁边的）
- 设置页「检查更新」：题库和界面热更新（只下载改动的文件），程序本身有新版时自动下载替换并重启

安卓手机版：从 [Releases](https://github.com/chen-pi-2007/zhixue-tiku/releases) 下载 `zhixue-tiku.apk` 安装，离线刷题（没有技能实操和导入试卷）。

也可以用 `start.bat`(或 `python server.py`)以命令行窗口方式运行。

**维护、发布新版本、接手项目：看 [MAINTAINING.md](MAINTAINING.md)。**

## 功能

| 功能 | 说明 |
|---|---|
| 📅 今日复习 | 首页一键开始:到期该复习的题(错题优先)+ 每日若干新题(各科轮流,薄弱题型优先);做错的题本轮末尾再出一次 |
| 🧠 间隔复习 | 每道题按掌握程度安排下次复习(1→2→4→7→15→30 天);同一天反复答对只算一次进步 |
| 🔥 错题本 | 做错自动收录;要在**不同的日子里连续答对 3 次**才算消灭;可手动标记掌握/重新加入、导出 txt |
| 📝 模拟考试 | 按科目蓝图组卷(英语分语音/词汇/对话/完形/阅读/图文/书面表达),限时、答题卡、交卷统一判分,出分项报告;错题自动进复习 |
| 📚 科目页 | 各科掌握度、按题型练习(标出薄弱题型)、按卷子顺序/乱序/只做新题 |
| 🖼️ 图片题 | 题干、材料、选项里的图片都能显示,点击放大;支持下划线和加点字 |
| 📤 上传识别 | 拖拽上传 docx/txt/md 试卷自动拆题(泛雅格式等) |
| ⏳ 学测倒计时 | 首页显示距离学测还有几天(默认 11 月 7 日,点日期可改) |
| 🛠️ 技能实操 | 计算机应用方向 5 套、网络技术方向 5 套技能卷,见下文 |

题库目前包括:语文 5 套、数学 5 套、思想政治 5 套、英语 7 类题库(官方答案)、数字媒体理论题 10 个题库,共 1877 题。

## 技能实操(计算机与网络技术类)

| 模块 | 怎么练 | 评分 |
|---|---|---|
| Word / Excel / PPT | “开始练习”把素材复制到 `data/skill_work/<卷>/` 并用 Office/WPS 打开,做完保存后点“检查评分” | 读取保存的文件逐项检查(页面、字体段落、表格、条件格式、图表、动画、切换……),按评分表给分并说明错在哪 |
| 网页设计 | 同上,用 Dreamweaver 打开 index.html | 检查框架、CSS、表格、图片、链接、表单 |
| 信息录入 | 网页里限时打字(禁止粘贴) | 按评分表的速度对照表,错字/多字/缺字/多余空格各扣 0.2 |
| 程序填空 | 代码里直接填空 | 按评分表参考答案(含等价写法)判分 |
| 网络组建 | 每台设备粘贴 `show running-config`(+`show vlan brief`) | 命名、VLAN、IP、静态路由/OSPF/RIP、Trunk、telnet、特权密码逐项判分;PC 设置自查 |
| 组装 / 综合布线 / 服务器架设 | 对照评分标准逐项打勾 | 自查得分 |

右上角“📖 答案模式”:Office 题显示参考答案的逐页图片(由参考答案导出,没装 Office 的电脑也能看)、网页题直接显示参考网页、程序填空显示答案、网络组建显示标准配置命令。参考答案本身有几处不符合题目要求,页面上有提示,判分以题目要求为准。

技能题库包由 `学测/_脚本/build_skills.py` 生成(需要本机 Office),`import_packs.py` 导入时会一起复制到 `data/skills/`。检查器在 `skills/`,回归测试 `tests/test_skills.py` 用参考答案(应满分)和原始素材(应 0 分)校验每一条规则。

## 数据

- `data/bank.json`:题库内容(卷子+题目),可以从题库包重新导入
- `data/progress.json`:**学习进度**(复习卡片、每次作答记录、模拟考试),这个最重要,要备份
- `data/media/`:题目图片

题目用稳定的 key(`<卷子key>#<序号>`)关联进度,重新导入同一题库包不会丢做题记录。

## 题库包(大批量导入,含图片)

题库包由 `学测/_脚本/` 生成:

```
cd 学测/_脚本
python extract_images.py   # 用 Word 把含图题库转 docx、导出图片(只需跑一次)
python build_packs.py      # 生成 学测/题库包/*.json + media/
```

然后**先关掉网页服务**,再导入:

```
cd quiz-app
python import_packs.py ../学测/题库包
```

## 支持的试卷格式

内置规则引擎(离线可用)已覆盖:

- **泛雅/学习通导出格式**:`1.【单选题】题干… A.选项 B.选项` + `答案:A`(政治卷即此格式)
- **传统大题结构语文卷**:`一、基础知识… 二、阅读理解… 三、古代诗文阅读… 四、默写… 五、综合实践… 六、写作`,自动按大题归类题型,阅读/情境材料自动挂到每道题前
- 单选题 / 多选题 / 是非题 / 问答题(问答题收录为参考答案自评)
- 选项与题干挤在同一行、多个选项挤在一行、题号缺失、材料题多段题干
- 是非题文字答案(对/错/√/×/T/F)
- 卷尾集中答案表(`1.B 2.A 3.D …`)
- 无【题型】标签的普通编号试卷、txt/md(自动识别 UTF-8 / GBK 编码)

> 说明:旧版 .doc 需先另存为 .docx(本机装有 WPS/Word 时可一键转换)。
> 上传没有答案的卷子时题目仅入题库浏览;五套《语文》练习卷的参考答案与逐项解析已内置。

### AI 兜底解析(可选)

遇到规则引擎不认识的格式时,可配置大模型自动解析:编辑 `config.json`,填入任意
OpenAI 兼容接口(智谱 GLM / DeepSeek / OpenAI 等)的 `api_key` 即可。
不配置也完全不影响日常使用。

## 换电脑 / 备份

整个项目零依赖、数据就是一个 JSON 文件,任意一种方式都能完整继承(代码 + 题库 + 错题记录):

**方式一:一键打包(最简单,适合一次性搬家)**
双击 `backup.bat`,自动把整个项目打包成 zip 放到桌面。
新电脑:解压到任意目录 → 双击 `start.bat`(只需电脑装有 Python 3.6+)。

**方式二:Git 私有仓库(适合两台电脑长期同步)**

```bash
cd quiz-app
git init
git add .
git commit -m "题库+错题记录"
git remote add origin <你的私有仓库地址>
git push -u origin master
```

新电脑 `git clone <仓库地址>` 后双击 `start.bat` 即可。注意:
- 仓库务必设**私有**(里面有个人学习记录)
- 国内访问 GitHub 不稳的话用 Gitee(码云)
- `data/` 整个目录(尤其 `progress.json`)就是要同步的数据,不要把它加进 .gitignore
- 换电脑刷完题后记得 `git add . && git commit -m "同步" && git push`,另一台电脑 `git pull`

**方式三:网盘同步目录**
把 `quiz-app` 放进 OneDrive/坚果云 等同步目录,自动双向同步。
注意不要两台电脑同时开服务刷题(同时写 data/ 会互相覆盖)。

## 常见问题

- **上传 .doc 报错**:旧版 .doc 请先用 Word 另存为 .docx
- **PDF 暂不支持**:先转成 docx 或 txt
- **端口被占用**:自动改用下一个端口;也可在 `config.json` 里改 `port`
